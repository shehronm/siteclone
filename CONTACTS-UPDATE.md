# MIRWINK — публичные контакты

Обновление 5 октября 2026 года по указанию владельца:

- Почта: **mirwink@mail.ru**.
- Telegram: **https://t.me/mirwink** (**@mirwink**).

Контакты заменены в обеих языковых версиях: подвал, крупная надпись почты, окно заявки, запасная почтовая ссылка формы, запасная ссылка Telegram при ошибке, контакт в окне конфиденциальности и Organization JSON-LD. HTML и React Flight согласованы.

Два клиентских модуля получили новые имена `18zr536gj0psb-mirwink-contacts1.js` и `0cqqckwhc3qa9-mirwink-contacts1.js`; страницы подключают новые файлы, чтобы посетители не получали прежний контакт из кеша. Старые модули оставлены для совместимости со старыми страницами. Новые страницы их не подключают.

Уточнено фактическое описание обработки данных: выбранный язык запоминается cookie, тема хранится в браузере, Vercel Speed Insights измеряет производительность, а параметры запроса и фрагменты URL удаляются перед отправкой событий. Убрано ошибочное утверждение об отсутствии аналитики и устаревшие названия проектов из окна конфиденциальности. Это техническое описание поведения, а не заключение о соответствии законодательству.

Серверный получатель заявок не менялся: публичный Telegram-профиль и `TELEGRAM_CHAT_ID` — разные настройки. Изменение ссылок не создаёт почтовый ящик и не подтверждает получение писем. На момент проверки публичная страница @mirwink открывалась с отображаемым именем «Лао»; владение указано пользователем, отдельно не проверялось.

Проверки: JSON-LD и Flight согласованы, JavaScript синтаксически корректен, существующие 27 тестов API/языка прошли; оба окна EN/RU проверены в Chromium при 320/390/1440 px без горизонтального переполнения, загрузка формы и новые ссылки подтверждены. Реальные письма и Telegram-заявки этим обновлением не отправлялись. Действующая опубликованная конфигурация WAF прочитана: POST /api/contact, 30 запросов/IP/60 секунд, active=true, firewallEnabled=true.

Результат публикации и ограничения оценки готовности приведены в отдельном отчёте поставки.
