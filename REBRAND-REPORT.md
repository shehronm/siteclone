# MIRWINK — переименование существующего сайта

Дата: 2 октября 2026. Подготовленный основной адрес: **https://mirwink.ru/**. Русская версия: **/ru**.

Обновлён существующий проект `work/project`, содержащий последнюю оптимизацию desktop-загрузки. Сайт не переписывался. Секции, сетка, композиция, шрифты, цветовая система, фото, анимации и функциональность сохранены. Бренд — MIRWINK; крупное начертание на первом экране — Mirwink, как прежнее title-case имя.

## Причина и реализация

Имя студии было одновременно в статическом HTML, React Flight, клиентских модулях и отдельной русской локализации. Поэтому замена только видимого HTML могла вернуть старое имя после гидратации. Обновлены все активные слои, demo-страницы, текстовые подписи SVG и заголовок Telegram-уведомления.

Новый заголовок содержит семь букв. На телефонах он не помещался в существующую половину сетки при прежнем размере. До 450 px размер теперь рассчитывается по фактической ширине содержимого ячейки, включая различия полосы прокрутки. Высота исходной строки сохранена. На desktop размер, шрифт и положение не менялись.

Изменённые клиентские модули получили новые имена файлов, CSS и RU-локализация — новый query version. Это предотвращает смешение брендов из старого кеша. Прежние immutable JS-файлы оставлены с исходными байтами; текущие HTML их не подключают.

Существующая монограмма M и favicon подходят новому названию и сохранены. В Open Graph используется PNG 1200×630, экспортированный из обновлённой исходной SVG-композиции; добавлены тип, размер, alt и Twitter card.

- **Playwright WebKit 26.5:** 52/52 сочетаний; обе серии взаимодействий завершены. Это проверка движка, не Safari на реальном iPhone/Mac.
- Ширины на каждом из двух движков: **320, 375, 390, 430, 768, 834, 1024, 1180, 1280, 1366, 1440, 1600, 1920 px**. Проверены границы текста заголовка, отсутствие горизонтального переполнения документа и секций, новый бренд, метаданные и mint-акцент.
- В обоих языках каждого движка: touch-меню и переход к команде, четыре окна сотрудников, шесть окон проектов, закрытие Escape и возврат фокуса для команды, grayscale фото, hover на desktop, reduced motion.
- Форма: validation, success и error state, сохранение введённого имени после ошибки. Ответ API в браузерных проверках **подменён**; реальные Telegram-заявки не отправлялись.
- **14/14** существующих contact/health тестов, провайдер Telegram подменён. Проверены validation, HTTP/malformed/oversized запросы, honeypot, отсутствие настроек, ответы и сбои провайдера, отсутствие секретов в ошибках/логах, readiness. Заголовок заявки проверяется как MIRWINK.
- Синтаксис **73 JS/CJS-файлов** проверен Node, ошибок нет.
- **8 холодных загрузок** EN/RU на 320, 375, 390, 430 px в Edge: заголовок помещается, горизонтального переполнения нет.
- **12 проверок demo:** все шесть HTML на 320 и 1440 px, страницы открываются, старого имени в видимом тексте нет, переполнения нет.
- **4 сравнения с предыдущим проектом:** EN/RU на 390 и 1440 px. Ширины и высоты всех секций совпали; preload шрифтов совпал; desktop-типографика заголовка совпала.
- Статическая проверка **105 текстовых файлов**: вне оставленных исторических JS-копий нет отдельного старого бренда и `miro.website`; восемь HTML проверены на существование локальных ресурсов. Canonical, hreflang, JSON-LD, OG/Twitter и cache versions проверены. PNG имеет 1200×630; слово Mirwink занимает x=50…645.625 внутри чёрного поля до x=800.
- Все **19 SVG** в `assets/miro` проверены по фактическим границам текста: подписи помещаются по ширине изображения. Sitemap разобран XML-парсером: две страницы и все языковые ссылки соответствуют новому домену.
- Визуально просмотрены desktop/mobile снимки Edge, mobile WebKit после завершения вступления и карточка ссылки. Монограмма/анимация WebKit дополнительно сравнены с исходным проектом; их поведение не изменено.

## Границы проверки

**Firefox не проверен успешно:** установленный Playwright Firefox завершился при создании пустой вкладки (`Cannot read properties of undefined (reading '_page')`), до навигации на сайт. Это не результат тестирования сайта. Safari, реальные iPhone/Android и новый production не проверялись в этой поставке.

Замеры LCP и другие показатели скорости **не повторялись** при переименовании. Предыдущая оптимизация сохранена, но исторические численные результаты не объявляются новыми.

Подключение `mirwink.ru`, DNS/HTTPS, публикация, production-настройки Telegram/WAF и перенастройка UptimeRobot не выполнялись. Canonical/OG/sitemap подготовлены именно для нового основного домена; перед production нужно подключить этот адрес и проверить уже опубликованный сайт. Новая реальная доставка Telegram не подтверждена этим прогоном.

Контактная почта `shehronm@mail.com` и существующий Telegram-профиль сохранены. Почта на новом домене и Instagram-ссылка не придуманы. Секретные переменные не входят в ZIP; в нём только шаблон `.env.example`.

Внутренний каталог `assets/miro`, CSS-классы, имена функций и старые копии JS сохранены ради структуры и совместимости. Два прежних raster-файла `discipline-product.png` / `discipline-systems.png` остаются историческими неиспользуемыми материалами: на страницах и в runtime-ссылках их нет, они указаны только в asset manifest. Их композиция отличается от одноимённых SVG, поэтому подмена изображения ради переименования не делалась.
