# Страницы услуг MIRWINK

Три направления, каждое на русском и английском:

- `/ru/services/ai-workspace` и `/services/ai-workspace`
- `/ru/services/telegram` и `/services/telegram`
- `/ru/services/crm` и `/services/crm`

## Как дополнить цифры

Откройте `content/service-metrics.json`. Для каждой услуги три объекта идут в том же порядке, что и карточки показателей на странице. Поля:

- `before` — измерение до внедрения;
- `after` — измерение после внедрения;
- `period.ru` и `period.en` — период или описание сопоставимых выборок на двух языках.

Замените `null` действительным числом без кавычек. Процент вводится числом от 0 до 100, знак `%` уже есть в макете. `0` — реальный нулевой результат; если данных нет, оставьте `null`. До заполнения вместо числа выводится тире, столбик графика остаётся пустым. При заполнении появляются соответствующие сравнительные столбики. Для процентов используется шкала 0–100; для времени обе полосы имеют общую шкалу по большему из двух значений.

Подписи, единицы и способ измерения находятся в `content/service-pages.json`, в `metrics` каждой услуги и языка. Смысл и единица одного показателя должны совпадать на обоих языках. Числа вводятся один раз и используются обеими версиями страницы. Источником значений служит только `service-metrics.json`.

После изменения выполните из папки проекта:

```powershell
npm run build:services
```

Затем опубликуйте обновлённые HTML-файлы обычным способом. Для ручной сборки страниц установка новых пакетов не нужна: генератор работает на стандартном Node.js.

Можно просто прислать цифры в чат в формате «услуга / название показателя / до / после / период» — тогда их внесу я. Не присылайте клиентские персональные данные для этой операции.

## Где менять содержание

`content/service-pages.json` — все тексты трёх страниц в RU/EN. `scripts/generate-services.cjs` — общий шаблон и схемы процессов. `services/service-pages.css` — визуальное оформление. `services/service-pages.js` — мобильное меню и тема.

Тексты страниц написаны как предложение услуги, а не отчёты о вымышленных внедрениях. Неизвестные цифры и результаты не заявлены. Новые кейсы с подтверждёнными данными можно добавить отдельными материалами позже.

`scripts/`, `content/` и Markdown-документы исключены из публикации через `.vercelignore`, но сохранены в репозитории и архиве. Публичные страницы содержат готовый текст, работающий без JavaScript, и не требуют доступа к исходным JSON.

Заявка открывается в существующей форме на главной. API и настройки доставки не изменены. Новые страницы имеют отдельные canonical, языковые ссылки и разметку услуг. Добавление страниц не гарантирует первую позицию или изменение ИИ-ответов поисковиков.
