# MIRWINK — настройки поиска

Обновлено 4 октября 2026 года. Рабочий проект: `siteclone`. Основной сайт: https://mirwink.ru/. Русская версия: https://mirwink.ru/ru.

## Выполнено

- Опубликована актуальная версия MIRWINK вместо версии с метаданными MIRO DIGITAL / miro.website.
- Основной хост без www отдаёт HTTP 200; www перенаправляется на него с HTTP 308 с сохранением пути.
- EN/RU имеют собственные canonical, взаимные hreflang и согласованные Open Graph URLs. В sitemap только две основные страницы; robots.txt разрешает обход и указывает правильную карту.
- В обеих страницах согласованы Organization и WebSite JSON-LD в HTML и данных React Flight. Название MIRWINK, альтернативные написания Mirwink и Мирвинк, настоящий существующий контакт и логотип. Рейтинги, адреса и достижения не добавлялись.
- /index.html и /ru/index.html перенаправляются на / и /ru. API получает X-Robots-Tag: noindex. Существующий noindex страниц портфолио demos сохранён.
- Владение https://mirwink.ru/ подтверждено в Google Search Console через HTML-файл и в Яндекс Вебмастере через HTML-файл.
- https://mirwink.ru/sitemap.xml отправлен в оба сервиса; при отправке карты приняты в очередь. Это не равно завершённой индексации всех URL.
- Главная и /ru отправлены на переобход в Яндекс.
- При проверке URL Google уже показывал главную в индексе; canonical выбран как https://mirwink.ru/, получение страницы успешно, обход и индексация разрешены.
- В Google отдельно приняты запросы на индексирование главной и /ru. При повторной проверке 4 октября обе страницы уже подтверждены в индексе. Для /ru Google выбрал canonical https://mirwink.ru/ru, получение успешно, обход и индексация разрешены; sitemap распознан как источник обнаружения.
- Версия сайта сохранена в GitHub `shehronm/siteclone`, коммит `65a482c`. Автоматическая production-сборка Vercel для этого коммита имеет статус READY. Публичные HTML EN/RU, robots, sitemap и файлы подтверждения совпали с проверенными локальными файлами.

Отдельный проект miro.website и его настройки поиска не изменялись по уточнению владельца. Смена адреса этого проекта не заявлялась.

В отчёте Sitemap Google первоначально отображалось «Не получено / Не удалось обработать файл Sitemap». После успешной проверки доступа инструментом Google и одной повторной отправки карты статус в Search Console стал «Успешно», выявлено 2 страницы (проверено 4 октября). Подключённый API ещё возвращал isPending=true, поэтому актуальный результат подтверждён непосредственно интерфейсом Google. В Яндексе заявка на /ru уже обработана, главная остаётся в очереди; карта также ожидает обработки. Обработанная заявка на переобход сама по себе не подтверждает индексацию страницы Яндексом.

## Следующие публикации

Сохранять HTML-файлы подтверждения Google и Яндекса. Не заменять адреса в sitemap/canonical старым доменом. Не добавлять запрет индексации на главную и /ru. При изменении основного хоста одновременно менять Vercel redirect, canonical, hreflang, OG, JSON-LD, robots и sitemap.

Search Console использует URL-prefix ресурс https://mirwink.ru/. Он охватывает HTTPS-адреса этого хоста. DNS Domain property не создавался.

## Проверки

Локально: 14 тестов API с подменой провайдера, без реальных заявок; Edge и WebKit, EN/RU × 320/390/1440/1920 px, совпадение SSR/Flight/DOM метаданных и схем, отсутствие переполнений/ошибок JavaScript. WebKit — движок автоматизации, не физический Safari/iPhone.

Перед переключением домена: защищённая Vercel-сборка, HTML EN/RU, готовность API, файлы подтверждения. После переключения: реальные HTTPS-ответы, sitemap, robots, редиректы и подтверждение владения в обоих кабинетах.

## Как оценивать результат

Отслеживать запросы mirwink и мирвинк в отчётах Google/Яндекса: показы, клики, позиция, выбранная страница. Не оценивать результат только по персонализированной выдаче своего браузера. Индексация и первая позиция — разные результаты; первое место не гарантируется. Карты и запросы обхода не следует отправлять многократно без новых изменений.

Официальные инструкции: https://developers.google.com/search/docs/appearance/site-names и https://yandex.ru/support/webmaster/ru/robot-workings/new-changed.
