# MIRWINK

Существующий сайт студии, переименованный из MIRO DIGITAL в MIRWINK. Основной адрес для SEO — `https://mirwink.ru/`, русская версия — `/ru`.

Это готовый статический экспорт с клиентскими JavaScript-файлами и двумя Vercel Functions в `api/`. Исходных React/JSX-компонентов в переданном проекте нет. Сетка, секции, шрифты, анимации и предыдущая оптимизация загрузки сохранены.

## Публикация

1. Загрузите содержимое папки проекта в существующий Vercel-проект. Framework Preset — Other; Install Command — `npm ci` (или автоматическая установка Vercel); Build Command не нужен; Output Directory — корень проекта. Настройки Node указаны в `package.json`. Пакет `@vercel/functions` нужен для выбора языка в Routing Middleware.
2. Сохраните действующие переменные окружения Telegram. Список названий — в `.env.example`; настоящие значения в архив не входят. Описание API и настроек — в `CONTACT-SETUP.md`.
3. В Vercel → Settings → Domains добавьте `mirwink.ru`, а при необходимости `www.mirwink.ru` с перенаправлением на основной адрес. В REG.RU задайте DNS-записи, которые покажет именно ваш проект Vercel. Сохраните нужные записи почты, если она уже используется.
4. Дождитесь подтверждения домена и HTTPS. После публикации проверьте главную, `/ru`, `/api/health`, заявку через форму и оповещения мониторинга. Текущие мониторы старого Vercel-адреса автоматически на новый домен не переходят.

3 октября 2026 года актуальная версия опубликована в существующем проекте Vercel `siteclone`. Основной адрес — `https://mirwink.ru/`; `www.mirwink.ru` перенаправляется на него с HTTP 308. Проверены HTTPS, canonical, hreflang, Open Graph, JSON-LD, robots.txt и sitemap.xml. Отдельный проект с доменом `miro.website` не изменялся. Настройки поисковых систем и ограничения проверки описаны в `SEO-SETUP.md`.

Публичные контакты с 5 октября 2026 года: `mirwink@mail.ru`, Telegram — `https://t.me/mirwink` (@mirwink). Новая почта на домене и Instagram-аккаунт не создавались. Уведомление заявки теперь начинается с «Новая заявка · MIRWINK».

## Проверки

Для тестов API используется Node.js 24:

```sh
npm test
```

Перед первым запуском тестов выполните `npm ci`. Правила языка, favicon и проверки выпуска от 4 октября 2026 года описаны в `LANGUAGE-UPDATE.md`.

Последние правки интервалов Mirwink, карточек команды и текстов портфолио описаны в `UPDATE-REPORT.md`. Предыдущий этап переименования — в `REBRAND-REPORT.md`. Старые отчёты сохраняют исторические результаты прежних выпусков; они не подтверждают проверки новой публикации.

Каталог `assets/miro`, CSS-классы и прежние неиспользуемые версии JS оставлены для совместимости структуры и кеша. Пользовательские страницы используют новый бренд и новые версии изменённых клиентских модулей.
