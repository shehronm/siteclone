# MIRO DIGITAL — изменения и проверка

Дата: 25–27 сентября 2026 года.

Доработан существующий проект из «Новая папка.zip». Сохранены страницы, секции, компоненты, медиа, локальные шрифты, исходная система анимаций и пути проекта. В архиве находился готовый HTML/React-экспорт с клиентскими чанками, а не исходники компонентов Next.js. Поэтому изменения внесены в имеющиеся HTML, CSS, API и соответствующие клиентские модули; новая версия сайта с нуля не создавалась.

**Что исправлено и почему**

| Область | Причина | Изменение |

| LET’S BUILD WHAT’S NEXT | Баннер наследовал отрицательный трекинг основного текста на очень крупном кегле | Нормализованы letter-spacing и kerning в существующем баннере. LET’S остаётся одним словом в одной чёрной плашке. LET’S / BUILD / WHAT’S — белые на чёрном; NEXT — чёрный на белом; стрелка mint. Кегль, порядок и анимация слов сохранены. |

JSON ограничен 16 KiB с проверкой как `Content-Length`, так и разобранного тела. Журналируется только исход доставки без данных заявки и секретов. |

Секции и карточки сохранены. Перед production содержимое портфолио всё равно требует утверждения владельцем. |
| Публичные данные страницы | Во встроенных данных HTML находились локальные Windows-пути к фото и служебные заметки | Пути заменены на публичные адреса существующих фото, служебные заметки очищены при сохранении структуры данных. |
| SEO основного домена | После подтверждения `miro.website` относительные canonical и отсутствие sitemap не давали готовой настройки индексации | В EN/RU добавлены абсолютные `canonical`, `hreflang`, Open Graph URL/изображение и URL организации; созданы `robots.txt` и `sitemap.xml` для двух основных страниц. Локальные DOM/HTTP-проверки прошли; сам домен ещё не проверен. |
| Фокус в модальных окнах | Закрытие диалога по Escape оставляло клавиатурный фокус на `body` | В существующем `case-context.js` сохраняется открывший элемент и фокус возвращается к нему после закрытия. Проверено 12 сценариев EN/RU × 390/1440 px × contact/project/team. |

Новые правила overflow:hidden для маскировки проблем не добавлялись. Существующие overflow для анимаций и внутренних скроллеров сохранены. Число !important в miro.css уменьшилось с 213 до 205; новый слой из десятков !important не добавлялся.

**Что остаётся перед production**

По вашему уточнению сохранён Telegram. На первоначальном preview подтверждён error state без настроек. Затем тестовые серверные переменные добавлены только в Preview; одна настоящая заявка получила HTTP 200, success state, запрет повторной отправки и contact.delivery/sent в журнале. Владелец подтвердил получение сообщения в нужном чате. Production-доставка и её настройки не проверены. Автоматической email-рассылки нет: email включается в Telegram-заявку, mailto остаётся запасным способом связи.

Основной домен для SEO указан владельцем как `miro.website`. Доступ к Vercel получен через подтверждённый CLI-вход. Обновлённый пакет опубликован в защищённом preview https://siteclone-hdip9rahp-shehron-e3755251.vercel.app (READY), production не менялся. В проекте siteclone, команда shehron-e3755251, подключён только siteclone-self.vercel.app; miro.website отсутствует. На miro.website работает другая страница и sitemap из десяти URL. Замена этого сайта не согласована и не выполнялась. Проверка публичного GitHub shehronm/siteclone подтвердила отсутствие исходных компонентов и frontend CI/build; это ограничение корпоративного сопровождения.

На Vercel подготовлен черновик ограничения запросов только для preview: POST /api/contact, 30/IP/60 секунд, log. Черновик не опубликован и не обеспечивает блокировку. После первоначальной проверки секреты добавлены только в Preview; реальная доставка подтверждена. Инструкция и актуальное решение о готовности — в PRE-DEPLOY-AUDIT.md.

Safari, Firefox, реальные iOS/Android, нагрузочная устойчивость и полная сертификация доступности не проверялись. Код существующих анимаций и визуальные бренды вложенных демонстраций сохранены.
