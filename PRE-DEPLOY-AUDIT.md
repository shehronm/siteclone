## Что проверено

- **Опубликованная прежняя версия:** EN/RU, 13 ширин 320–1920 px, меню, окна команды и проектов, клиентская валидация и наличие прежних дефектов. Реальная заявка на ней не отправлялась. Повторный read-only HTTP-запрос показал `siteclone-self.vercel.app` с title «MIRO DIGITAL — Websites, Products & Automation», HTML около 286 KiB и `miro.css?v=60`; `miro.website` отвечает HTTP 200 с title «MIRO — Digital Studio» и HTML около 15 KiB. Это не доказывает идентичность или различие Vercel-проектов; новая версия сайта на этих адресах не подтверждена.
- **Локальный пакет в Microsoft Edge/Chromium через Playwright:** EN/RU × light/dark × 13 ширин = 52 сочетания. Проверены mint `rgb(161, 255, 203)`, контраст информационной панели, разделительные линии, границы секций, отсутствие измеренного горизонтального переполнения, ошибок страницы и ответов 4xx/5xx для ресурсов. Дополнительно проверены 78 сочетаний ширин/языков на трёх демонстрационных страницах.
- **Сценарии:** все 6 окон проектов и все 4 bio команды в обеих языковых версиях; 26 проверок contact modal на 13 ширинах в EN/RU, обязательные поля, email, локальный ответ API 503 без секретов, error state, сохранение данных, клавиатура и эмуляция touch. Локальный путь браузер → API → заглушка Telegram проверен для успеха, отказа и таймаута: 12 сценариев EN/RU. Настоящее сообщение в Telegram эти прогоны не посылали.
- **Автотесты API:** `npm test` — 13/13, включая JSON >16 KiB с указанным, отсутствующим и некорректным `Content-Length`; провайдер Telegram подменён. После финального изменения кода синтаксис и состав полного ZIP перепроверяются перед передачей.
- **Базовая семантика:** EN/RU имеют разные `title`, `lang`, H1/H2 и описания; у 34 изображений на каждой странице есть `alt`; среди видимых кнопок/ссылок не выявлено элементов без текстового имени, дублирующихся `id` нет. Это быстрый DOM-аудит, без оценки качества alt и скринридера.
- **Локальный performance-lab:** в сопоставимых прогонах Edge при ограничении 1,6 Mbps / 150 мс и CPU ×4 CLS до/после составил 0,9603 → 0,0270 на 390 px и 0,9341 → 0,0008 на 1440 px. После правки FCP — 1,66/1,56 с, LCP — 1,66/2,91 с соответственно. Это синтетический локальный замер, не полевые Core Web Vitals; результаты и особенно LCP на desktop нужно перепроверить на staging.
- **Визуально:** просмотрены отдельные desktop, tablet и mobile кадры hero, баннера, команды, формы и стыков в обеих темах. Каждый пиксель и физические устройства вручную не просматривались.

## Черновик защиты API

В Vercel создан и прочитан полный diff единственного нового правила `rule_contact_form_preview_rate_limit_NgJduW`. Все условия объединены AND: точный host текущего preview siteclone-91348inlk-shehron-e3755251.vercel.app, environment=preview, path=/api/contact, method=POST. Порог — 30 запросов на IP за 60 секунд, fixed_window, действие при превышении — log. **Не опубликовано; защиты production и фактического ограничения запросов пока нет.** Log даже после публикации лишь записывает совпадения. Порог — начальный для наблюдения, а не результат нагрузочных испытаний.

Согласно применённому Vercel Firewall SKILL.md: “Stage drafts; let the user publish.” Публикацию пользователь выполняет сам после просмотра diff в https://vercel.com/shehron-e3755251/siteclone/firewall. Служебный доступ к защищённому preview не подходит для доказательства WAF enforcement; после согласованного включения блокировки нужен отдельный ограниченный тест 429. Новый preview URL потребует обновления host в черновике.
